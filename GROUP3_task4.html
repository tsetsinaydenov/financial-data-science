  • Vanilla components: straddle consists of

  • a call and put option

  • written on the same underlying asset

  • with the same Strike Price K

  • and same maturity T

    Types:

    |Long Straddle | Short Straddle| |---|---| |Long Call + Long Put | Short Call + Short Put|


-> This analysis focuses on the long straddle, because it is the standard version of the strategy and is well suited for understanding the main economic idea of benefiting from large price movements

4.1 A GENERAL DESCRIPTION OF AN OPTION'S PAYOFF STRUCTURE
(composition, payoff function, possibly conditions for payoff, etc.)

4.1.1 COMPOSITION OF PAYOFF STRUCTURE

The payoff of a straddle is a combination of the payoff of a call option and the payoff of a put option. The initial option premiums are not included in the payoff itself. They are relevant for the profit and risk profile, which will be considered later in the analysis.


Payoff functions of the call and put option:

$$ \text{Payoff}_{Call}= \max(S_T - K,0) $$

$$ \text{Payoff}_{Put} = \max(K - S_T,0) $$

Payoff-structure of the long straddle:

$$ \text{Payoff}_{straddle} = \max(S_T-K,0) + \max(K-S_T,0) = |S_T-K| $$


4.1.2 PAYOFF CONDITIONS AT MATURITY


$$ \text{Payoff}_{Straddle} = \begin{cases} K - S_T, & S_T < K, \\ 0, & S_T = K, \\ S_T - K, & S_T > K. \end{cases} $$

Case 1: $S_T < K$

The put option is in-the-money and the call option expires worthless. The payoff of the straddle is therefore generated by the put option:

$$ \text{Payoff}_{Straddle} = K - S_T $$

Case 2: $S_T = K$

Both options are at-the-money and have no intrinsic value at maturity. Therefore, the total payoff is:

$$ \text{Payoff}_{Straddle} = 0 $$

Case 3: $S_T > K$

The call option is in-the-money and the put option expires worthless. The payoff of the straddle is therefore generated by the call option:

$$ \text{Payoff}_{Straddle} = S_T - K $$

4.2 DEFINE FUNCTION OF BLACK-SCHOLES-MODEL
A function bsOption() that returns either the values of European call or put options for given input parameters, in a vectorized manner

4.2.1 GENERAL PARAMETER DEFINITION:


  • S : Current stock price of underlying asset
  • K : Strike Price
  • $\tau$ = T - t : Remaining time to maturity
  • r : Risk-free rate
  • sigma : Volatility

4.2.2 DEFINITION OF THE BLACK-SCHOLES-MODEL FORMULA


$$ d_1 = \frac{ \ln\left(\frac{S}{K}\right) + \left(r + \frac{1}{2}\sigma^2\right)\tau }{ \sigma \sqrt{\tau} } $$

$$ d_2 = d_1 - \sigma \sqrt{\tau} $$

Call Price: $$ \text{Call}_{BSM} = S \Phi(d1) - Ke^{-r\tau}\Phi(d2) $$ Put Price: $$ \text{Put}_{BSM}= Ke^{-r\tau}\Phi(-d2) - S\Phi(-d1) $$


The value of a long straddle can be obtained as the sum of the corresponding European call and put option prices:

$$ V_{\text{Straddle}} = C_{\text{BSM}} + P_{\text{BSM}} $$

# ---------------------------------------------------------------------------
# 4.2.3 BLACK-SCHOLES AUXILIARY FUNCTION
# ---------------------------------------------------------------------------


# DEFINE FUNCTION FOR d1, d2
def d1_d2(S, K, r, sigma, tau):
    # Condition for valid input parameters
    if sigma <= 0 or tau <= 0:
        raise ValueError("Volatility and time to maturity must be positive.")

    # Calculate d1 and d2
    d1 = (
        np.log(S / K) + (r + 0.5 * sigma**2) * tau
    ) / (sigma * np.sqrt(tau))
    d2 = d1 - sigma * np.sqrt(tau)

    return d1, d2

# ----------------------------------------------------------------------------
# 4.2.4 BLACK-SCHOLES-MODEL OPTION PRICING FUNCTION
# ----------------------------------------------------------------------------


# DEFINE BLACK-SCHOLES FUNCTION
def bsOption(S, K, r, sigma, tau, option_type):

    # Use d1, d2 from auxiliary function
    d1, d2 = d1_d2(S, K, r, sigma, tau)

    # Calculate price for european call
    if option_type == "Call":
        return S * norm.cdf(d1) - K * np.exp(-r * tau) * norm.cdf(d2)

    # Calculate price for European Put
    elif option_type == "Put":
        return K * np.exp(-r * tau) * norm.cdf(-d2) - S * norm.cdf(-d1)

    # Raise error if option type is neither call or put
    else:
        raise ValueError("Option type must be either Call or Put")

4.3.1 DELTA¶

4.3.1.1 CALCULATION

Measures much the option value changes when the underlying asset price changes by one unit

$$ \Delta = \frac{\partial V}{\partial S} $$

$$ \Delta_{Call}= \Phi(d_1) $$

$$ \Delta_{Put}= \Phi(d_1)-1 $$

$$ \Delta_{Straddle}= \Delta_{Call} + \Delta_{Put}

# ----------------------------------------------------------------
# 4.3.1.2 FUNCTION DELTA
# ---------------------------------------------------------------


# DEFINE FUNCTION FOR DELTA
# Delta of call option = N(d1)
def delta_call(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)  
    return norm.cdf(d1)               


# Delta of put = N(d1)-1
def delta_put(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return norm.cdf(d1) - 1


# Delta straddle: delta_straddle = delta call + delta_put
def delta_straddle(S, K, r, sigma, tau):
    return delta_call(S, K, r, sigma, tau) + delta_put(S, K, r, sigma, tau)

4.3.2 VEGA¶

4.3.2.1 CALCULATION

Measures the sensitivity of the option value with respect to the change in volatility


$$ \text{Vega} = \frac{\partial V} {\partial \sigma} $$

$$ \text{Vega}_{Straddle} = 2S \cdot \varphi(d_1) \cdot \sqrt{ \tau} $$

# DEFINE FUNCTION FOR VEGA

# Vega call
def vega_call(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return S * norm.pdf(d1) * np.sqrt(tau)


# Vega put
def vega_put(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return S * norm.pdf(d1) * np.sqrt(tau)


# Vega straddle: vega_straddle = vega_call + vega_put
def vega_straddle(S, K, r, sigma, tau):
    return vega_call(S, K, r, sigma, tau) + vega_put(S, K, r, sigma, tau)

4.3.3 THETA¶

4.3.3.1 CALCULATION

Measures how the option value changes as time passes


Theta shows how the option value changes as time passes.

$\tau$ denotes the remaining time to maturity:

$$ \tau = T - t $$

$\tau$ becomes smaller if time passes. Therefore, Theta is usually negative for long options, because they lose time value over time.

$$ \Theta = \frac{\partial V}{\partial t} = -\frac{\partial V}{\partial \tau} $$


$$ \Theta_{Call}= -\frac{S \cdot \phi(d_1)\cdot \sigma}{2\sqrt{\tau}}-rKe^{-r\tau}\ N(d_2) $$

$$ \Theta_{Put}= -\frac{S \cdot \phi(d_1)\cdot \sigma}{2\sqrt{\tau}}+rKe^{-r\tau} N(-d_2) $$

$$ \Theta_{Straddle}= -\frac{S \cdot \phi(d_1)\cdot \sigma}{\sqrt{\tau}}+rKe^{-r\tau}\Big(N(-d_2)-N(d_2)\Big) $$

# --------------------------------------------------------
# 4.3.3.2 FUNCTION THETA
# --------------------------------------------------------


# DEFINE FUNCTIONS
# Theta call
def theta_call(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return (
        - (S * norm.pdf(d1) * sigma) / (2 * np.sqrt(tau))
        - r * K * np.exp(-r * tau) * norm.cdf(d2)
    )


# Theta put
def theta_put(S, K, r, sigma, tau):
    # Vaues from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return (
        - (S * norm.pdf(d1) * sigma) / (2 * np.sqrt(tau))
        + r * K * np.exp(-r * tau) * norm.cdf(-d2)
    )


# Theta straddle = theta call + theta put
def theta_straddle(S, K, r, sigma, tau):
    return theta_call(S, K, r, sigma, tau) + theta_put(S, K, r, sigma, tau)

4.3.4 GAMMA¶

4.3.4.1 Calculation

Measures how much Delta changes when the underlying asset price changes by one unit

$$ \Gamma = \frac{\partial^2 V}{\partial S^2} $$

Because gamma is the same for call and put: $$ \Gamma_{Straddle}=2\cdot\frac{\phi(d_1)}{S \sigma \sqrt{\tau}} $$

# DEFINE FUNCTION GAMMA
# Gamma call/put
def gamma_call_put(S, K, r, sigma, tau):
    # Values from function d1, d2
    d1, d2 = d1_d2(S, K, r, sigma, tau)
    return norm.pdf(d1) / (S * sigma * np.sqrt(tau))


# Gamma straddle
def gamma_straddle(S, K, r, sigma, tau):
    return 2 * gamma_call_put(S, K, r, sigma, tau)

INTERPRETATION OF THE INTERACTIVE PLOT

  1. VOLATILITY $\sigma$:
  • Higher volatility increases the probability of large upward or downward movements
  • Straddle benefits from strong movements
    • strong upward movement benefits Call
    • strong downward movement benefits Put

=> Option price increases with volatility


  1. TIME TO MATURITY $\tau$:
  • If time to maturity increases, the value of the long straddle increases
  • A longer time horizont gives more opportunity for large price movement
  • If time to maturity decreases, the option loses time value

=> Option price increases with $\tau$


  1. RISK-FREE RATE r:
  • If the risk-free rate increases, the call price increases and the put price decreases
  • This leads to a mixed effect on the straddle
  • The impact of the interest rate is less important than other parameters

  1. STRIKE PRICE K:
  • Shifts the center of the straddle
  • If K increases, the put becomes more valuable and the call becomes less valuable
  • If K decreases, the call becomes more valuable and the put becomes less valuable

# 1. DEFINE PROFIT FUNCTION OF LONG STRADDLE

def straddle_profit_function(S, S_t, K, r, sigma, tau):

    # 1.1 CALCULATE PREMIUMS FOR CALL, PUT, STRADDLE

    call_premium = bsOption(S, K, r, sigma, tau, "Call")
    put_premium = bsOption(S, K, r, sigma, tau, "Put")
    total_premium = call_premium + put_premium

    # 1.2 GENERATE POSSIBLE STOCK PRICES AT MATURITY
    S_values = np.linspace(50, 150, 300)

    # 1.3 CALCULATE PROFIT FOR STRADDLE
    # Payoff for call, put, straddle at maturity
    call_payoff = np.maximum(S_values - K, 0)
    put_payoff = np.maximum(K - S_values, 0)
    straddle_payoff = call_payoff + put_payoff

    # Straddle profit = straddle payoff - total premium
    straddle_profit = straddle_payoff - total_premium

    # 1.4 CALCULATE REALIZED PROFIT
    # Realized payoff for stock price at maturity
    realized_call_payoff = max(S_t - K, 0)
    realized_put_payoff = max(K - S_t, 0)
    realized_straddle_payoff = realized_call_payoff + realized_put_payoff

    # realized profit = realized payoff - total premium
    realized_profit = realized_straddle_payoff - total_premium

    # 1.5 CALCULATE BREAK-EVEN
    # Calculate break-even points
    breakeven_low = K - total_premium
    breakeven_up = K + total_premium

    # 1.6 CALCULATE LIMITATIONS

    # Maximum total loss
    maximum_loss = total_premium

    # Maximum profit if stock price at maturity falls to 0
    maximum_downside_profit = K - total_premium  

    # Maximum upside profit 
    maximum_upside_profit = "unlimited"

    # 1.5 VISUALIZATION
    # Set figure size
    plt.figure(figsize=(12, 8))

    # Plot straddle profit
    plt.plot(
        S_values,
        straddle_profit,
        label="Long Straddle Profit",
        linewidth=2,
    )

    # Add horizontal line at profit = 0
    plt.axhline(0, color="grey", linestyle=":")

    # Add vertical lines for strike price and break-even points

        color="orange",
        linestyle="--",
        label=f"Lower Break-even = {breakeven_low:.2f}",
    )
    plt.axvline(
        breakeven_up,
        color="orange",
        linestyle="--",
        label=f"Upper Break-even = {breakeven_up:.2f}",
    )

    # Fill areas for profit and loss zones
    plt.fill_between(
        S_values,  # X-values 
        straddle_profit,  # Y-values
        0,  # Reference line for filling

        alpha=0.2,  # Transparency for filling

4.5.2.2 RISK PROFILE


- The maximum loss of a long straddle is limited to the total premium paid for the call and put option
  • The strategy becomes profitable when the stock price at maturity moves significantly far away from the strike price

maximum loss maximum profit
total premium paid theoretically unlimited
At $S_T$ ≈ K For $\lvert S_T - K \rvert > C_0 + P_0$ and $S_T \to \infty$

4.5.3 USE CASES AND EDGE CASES¶

4.5.3.1 EDGE CASES

Case Interpretation
$S_T = K$ Both options expire worthless; maximum loss equals $C_0 + P_0$
$S_T < K - (C_0 + P_0)$ The put payoff is large enough to generate a profit
$S_T > K + (C_0 + P_0)$ The call payoff is large enough to generate a profit
$\text{Break-even}_{low} < S_T < \text{Break-even}_{up}$ The strategy makes a loss because the price movement is not large enough to cover the premium
$S_T \to \infty$ Upside profit is theoretically unlimited
$S_T = 0$ Maximum downside profit is $K - (C_0 + P_0)$

4.5.3.2 USE CASES

  • when a strong movement of the underlying is expected, but the direction is unclear
  • for example:
    • Before earnings announcements
    • regulatory decisions
    • economic news
